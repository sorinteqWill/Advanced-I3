Tracking Pixel Awareness Demo

This page is for training and awareness purposes. It demonstrates how a very small remote image can be loaded when a user opens a page or email.

When this page loads, the browser will request a 1×1 image from a remote server. That request can be logged by the server.

In a real-world example, this technique is often used in email marketing to measure opens, but it can also be used to collect metadata such as when a message was viewed.
